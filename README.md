# 🏙️ Strategy City

Well-known trading strategies compete in four leagues (Nasdaq futures, stocks, crypto and hype) on real 15-minute data, with costs included. GitHub re-runs everything every 15 minutes and publishes the city as a web page.

- **settings.json** holds the season start dates, knockouts per day and position size.
- **arena-data** branch stores each season's price history (managed automatically).
- To update now: **Actions → Strategy City → Run workflow**.

A testing lab, not trading advice.
